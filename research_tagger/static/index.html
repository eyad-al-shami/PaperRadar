PAPER DETAILS

Save with Zotero Connector

This connects three things: PaperRadar in this tab, the Zotero desktop app, and the Zotero Connector browser extension. The translator is a small file that teaches the extension how to read our papers.

Install once · Mac and Chrome

  1. Open Zotero and check the browser extension.

    Open the Zotero desktop app. In Chrome, click the puzzle-piece Extensions icon beside the address bar. Find Zotero Connector and pin it so its button stays visible. If it is missing, install it from Zotero’s download page.

  2. Download the translator from this app.

    Download Research Tagger.js

    The file goes into your browser’s download folder, usually Downloads. Leave it as Research Tagger.js; you will copy it in the next step.

  3. Copy the file into Zotero’s translators folder.

    Switch to the Zotero desktop app. In the Mac menu bar, choose Zotero → Settings → Advanced. Find Files and Folders → Show Data Directory. Finder opens a folder; open its translators subfolder. Copy Research Tagger.js from Downloads into that subfolder.

    Expected result: Research Tagger.js sits alongside other .js files. This file is installed by copying it, not through Zotero’s Import command.

  4. Quit and reopen Zotero.

    In Zotero, press ⌘Q, then open Zotero again. Keep it running for the remaining steps.

  5. Reload translators in the Chrome extension.

    Return to Chrome. Right-click the Zotero Connector toolbar button → Options (or Preferences) → Advanced → Reset Translators. This reloads the extension’s translator list; it does not delete your Zotero papers. Then return to PaperRadar and refresh this tab with ⌘R.

  6. Check that PaperRadar is recognized.

    Open a conference that has papers. Hover over the Zotero Connector toolbar button: its tooltip should mention PaperRadar. If it only says Web Page, repeat steps 3–5 and check that Zotero desktop is open.

Save a paper or a batch

One paper

Click a paper title to open its dialog. Leave the dialog open, then click Zotero Connector in Chrome’s toolbar. Zotero saves that paper and attempts to attach its PDF.

Several papers

Close the paper dialog. Set your search, status, and tag filters, then click Zotero Connector in Chrome’s toolbar. In its selection window, check the papers you want and confirm. All matching pages are included.

Check your first save: switch to Zotero and expand the new paper using the arrow beside its title. A successful PDF download appears as a child attachment; double-click it to open it.

If the record saves without a PDF, check that the paper has a working PDF link here and that Zotero Settings → General → “Automatically attach associated PDFs and other files when saving items” is enabled. Papers marked [no PDF link] save metadata only. Saving again can create duplicates.

Using another browser or operating system? The same translator file is used. Open that browser’s Connector preferences and Zotero’s Advanced settings; menu names may vary. Find your Zotero data directory.
